# Remotion Project Videos

A collection of **programmatic video projects created with Remotion and Claude**.

This repository contains experiments exploring how AI can be used to generate motion graphics and complete video compositions through code instead of traditional timeline-based editing.

## About

I started this project after discovering that Claude can generate **Remotion/React code** for creating complex-looking motion graphics.

Instead of manually creating every animation in a video editor, I can describe the visual direction, provide assets such as voiceovers or images, and use Claude to generate the code that constructs the video.

The generated projects can then be opened in **Remotion Studio**, previewed, refined, and rendered into the final video.

## Workflow

```text
Idea / Script
      ↓
Voiceover & Assets
      ↓
Claude
      ↓
Remotion + React Code
      ↓
Remotion Studio
      ↓
Preview & Revisions
      ↓
Final Video
```
